# Mapeamento SGA

Preencha este documento antes de alterar o código.

## Campos principais

- `ID_OBRA`: identificador único da obra.
- `DATA_CORTE`: data da fotografia da obra.
- `DATA_FIM_VIGENTE`: prazo válido na data de corte.
- `DATA_CONCLUSAO_REAL`: marco institucional de conclusão.
- `PERCENTUAL_EXECUCAO_FISICA`: avanço físico conhecido na data de corte.

## Tabelas candidatas

- `tprojetodea`
- `tcontrato`
- `tpredio`
- `tfornecedor`
- `tparcela`
- `tlicitacao`
- tabelas de medições, aditivos e suspensões a confirmar.
